# Cars Compare

Сервис помогает сравнить условия покупки конкретного автомобиля в России и его привоза из Японии. Для этого он объединяет данные сервисов Drom: оценку средней цены автомобиля в России, статистику японских аукционов и расчёт стоимости привоза.

## Что умеет сервис

- Сопоставить выбранную комплектацию с объявлениями и статистикой цен в России.
- Показать примеры предложений на японских аукционах и среднюю цену в иенах.
- Показать период аукционной выборки, число лотов и средний пробег автомобилей в обеих выборках.
- Рассчитать ориентировочную стоимость привоза автомобиля из Японии.
- Найти объявления в России или автомобили под заказ на Drom с выбранным диапазоном лет.
- Собрать данные для сравнения в одном запросе. Некоторые характеристики автомобиля сервис определяет по выбранной модификации; при необходимости их можно указать явно.

Проект состоит из HTTP API на FastAPI и веб-интерфейса на React. Данные Drom и японских аукционов запрашиваются при обращении к сервису.

## Запуск через Docker Compose

Для запуска используйте Docker Compose — это основной и рекомендуемый способ работы с сервисом. Установите Docker с поддержкой Compose, перейдите в корень проекта и выполните:

```powershell
docker compose up --build
```

Для разработки используйте отдельный режим с автоматической перезагрузкой при изменении Python-файлов:

```powershell
docker compose -f compose.yaml -f compose.dev.yaml up --build
```

В обычном режиме API доступно на порту `8000`, веб-интерфейс — на порту `80`. Интерфейс проксирует запросы к API внутри Docker-сети.

## Документация и проверка работы

- Интерактивная документация API (Swagger UI): [http://localhost:8000/docs](http://localhost:8000/docs)
- Проверка доступности сервиса: [http://localhost:8000/health](http://localhost:8000/health)
- Веб-интерфейс: [http://localhost:80](http://localhost:80)

Список операций, параметры и форматы ответов смотрите в Swagger: документация строится FastAPI по текущей схеме API.

## Особенности сравнения

Расчёт строится для одного года и выбранной модификации. Параметр `generation_id` фиксирует поколение: одна модификация может встречаться в нескольких поколениях. Диапазон лет в отчёте меняет только ссылки поиска на Drom.

Российская цена — оценка Drom. Если она недоступна, интерфейс отдельно показывает среднее арифметическое положительных цен найденных похожих объявлений без повторов по ссылке. Эти предложения могут отличаться годом и комплектацией; это не статистика завершённых сделок.

Аукционная цена — среднее по лотам с положительной ценой в иенах на одной загруженной странице. Период ограничен известными датами этих лотов. Средний пробег считается по известным значениям, включая нулевой; интерфейс показывает полноту данных. Пробег российских автомобилей загружается для первых восьми карточек, с ограничением параллельных запросов и кешированием.

Предупреждения об экспорте — предварительная проверка характеристик автомобиля. Расчёт стоимости не подтверждает возможность поставки из Японии.

## Проверки перед коммитом

Интерфейс:

```powershell
npm --prefix frontend ci
npm --prefix frontend run lint
npm --prefix frontend test
npm --prefix frontend run build
```

Проверки API используют подменённые ответы и не обращаются к Drom. После сборки образа их можно запустить в Docker:

```powershell
docker compose run --rm --no-deps -v ./tests:/app/tests:ro -e PYTHONPATH=src api uv run --frozen --no-sync python -m unittest discover -s tests -v
```
